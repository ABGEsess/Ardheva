<h2>📌 Tentang Proyek</h2>
<p>
  <b>Ardheva Food & Snack</b> adalah aplikasi berbasis web yang dirancang untuk mempermudah proses pemesanan makanan dan camilan UMKM. Proyek ini dibuat sebagai bentuk kolaborasi tim organisasi kami di GitHub untuk mengimplementasikan pengembangan web full-stack tingkat awal.
</p>

<br>

<h2>✨ Fitur Utama Aplikasi</h2>

<table width="100%">
  <tr>
    <td width="50%" valign="top">
      <h3>👤 Muka Client (Pembeli)</h3>
      <ul>
        <li><b>Katalog Produk Interactive:</b>
          <ul>
            <li>🍡 Jajanan Kue Basah</li>
            <li>📦 Snackbox</li>
            <li>🍱 Nasibox</li>
            <li>🍛 Nasi Tumpeng</li>
          </ul>
        </li>
        <li><b>Metode Pembayaran Flexible:</b>
          <ul>
            <li>💵 Bayar Cash (Tunai)</li>
            <li>💳 Transfer / Payment Online</li>
            <li>🔒 Opsi Uang Muka (DP) & Pelunasan</li>
          </ul>
        </li>
        <li><b>Sistem Akun:</b> Registrasi & Login pelanggan.</li>
        <li><b>Form Pemesanan:</b> Input detail acara, tanggal, dan lokasi pengiriman.</li>
      </ul>
    </td>
    <td width="50%" valign="top">
      <h3>🛡️ Muka Admin (Pengelola)</h3>
      <ul>
        <li><b>Dashboard Penjualan:</b> Ringkasan statistik dan pesanan masuk.</li>
        <li><b>Manajemen Menu (CRUD):</b>
          <ul>
            <li>Tambah menu baru</li>
            <li>Edit harga & foto produk</li>
            <li>Hapus menu</li>
          </ul>
        </li>
        <li><b>Kelola Transaksi:</b> Verifikasi bukti pembayaran DP / Lunas.</li>
        <li><b>Status Pesanan:</b> Mengubah status pemrosesan pesanan hingga dikirim.</li>
      </ul>
    </td>
  </tr>
</table>

<ul>
  <li><b>Front-End:</b> HTML5, CSS3, JavaScript (DOM Manipulation)</li>
  <li><b>Back-End:</b> PHP Native</li>

<h2>🚀 Cara Memulai di Komputer Lokal</h2>

<details>
  <summary><b>Klik untuk melihat langkah instalasi lokal</b></summary>
  <br>
  <ol>
    <li><b>Clone repository ini:</b>
